# Fotos de Eventos

Coloca aquí las seis fotos de las tarjetas con estos nombres:

- `canto.jpg`: Festival infantil de canto.
- `danzas.jpg`: Encuentro de Danzas Tradicionales.
- `andina.jpg`: Muestra de música Andina.
- `ritmos.jpg`: Ritmos que encantan.
- `narracion.jpg`: Narración y música.
- `ensamble.jpg`: Canto y ensamble.

También puedes usar PNG, JPEG, WEBP o AVIF, conservando el nombre base. Reinicia `npm run dev` después de agregar archivos.

Mientras no estén las fotografías específicas, las tarjetas utilizan fotos que ya están en el proyecto. No es necesario cambiar código para reemplazarlas.

Los títulos de las últimas dos tarjetas son provisionales porque estaban tapados por la barra de navegación en la captura. Puedes editarlos en `src/EventsView.jsx`.
